# 单篇精读与偶尔复现

用户选定论文后读取 research-profile.md，定位并核对原文版本，建立 papers/<arxiv-id>/notes.md。
先给一页阅读地图：研究问题、已有方法的困难、本文贡献、章节路线、最少先修知识。以基本 QFT 和粒子物理为起点，用 B 衰变例子连接新知识，但不强行类比。
分段教学，每轮围绕一个核心问题：物理直觉→定义与约定→关键数学步骤→原文定位→物理解释→适用范围。注明哪些推导是补充的，避免一次倾倒整篇内容。
每个单元给 1—2 个检查理解的问题，记录用户明确反馈的困难和理解进度，不根据沉默推断掌握。
对新统计/AI 方法解释目标函数、数据假设、训练/验证划分、误差与偏差来源；区分物理约束与经验性能。
适合计算的例子优先提供可运行的最小 Python 示例，可与 Mathematica 思路对照；先检查现有环境，按实际需要添加依赖。
只有用户请求复现才进入 reproductions/<arxiv-id>/：先选一个公式、数值或图作为目标；列参数和缺失信息；实现最小计算；记录环境、命令、结果、误差及失败。明确区分教学简化、独立复现和运行作者代码。
